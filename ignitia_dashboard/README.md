# ignitia_dashboard

Admin dashboard for the Ignitia employee attendance & leave management system,
built with Flutter for the web.

This dashboard is a web port of the admin features from the
[i_employment](https://github.com/castaso/ignitia) Flutter app (mobile repo moved to
`castaso/ignitia_android`). It targets the
management side only: employee directory, holiday management, overtime approval
and shift management (a new module not present in the source app).

## Features

- Employee list & contact details (WhatsApp / call / email shortcuts)
- Holiday management (add / edit / delete)
- Overtime approval (approve / reject pending requests)
- Shift management (add / edit / delete / assign shifts to employees)

## Getting started

```bash
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://<host>:<port>/api/
```

The backend base URL defaults to `http://27.147.159.195:86/api/` and can be
overridden at build time with `--dart-define=API_BASE_URL`.

## Project structure

- `lib/models` - JSON models (employee, holiday, overtime, shift, security)
- `lib/repo` - REST services (`ApiService` via Retrofit) and API status helpers
- `lib/view_models` - Provider view models
- `lib/views` - Screens (login, dashboard home, employee, holiday, overtime, shift)
- `lib/components` - Reusable widgets
- `lib/utils` - Constants, strings, messages, navigation helpers

## Notes

- `.g.dart` files are generated by `build_runner`; keep them in sync with their
  source models (`dart run build_runner build`) when changing models.
- The shift module endpoints are provisional; align the paths in
  `lib/repo/api_service.dart` with the backend contract as it evolves.
